To get started, you will need [CraterLib](https://www.curseforge.com/minecraft/mc-mods/craterlib) and [Simple RPC](https://www.curseforge.com/minecraft/mc-mods/simple-discord-rpc) installed.

Once you have both installed in your mods folder, you can launch the game.


That's it. That's all you need to do for the most basic RPC setup, with pre-configured options.

:::warning In Game Config
If you want access to the in-game config screen, please ensure you have Cloth Config installed. If you are on Fabric or Quilt, you will also need ModMenu installed
:::
