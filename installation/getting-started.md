To get started with Maintenance Mode, you will need both the latest Maintenance Mode version, and latest [CraterLib](https://modrinth.com/mod/craterlib) version in your mods folder.

Depending on your mod loader, you will also need the Fabric API or Quilt Standard Libraries.

!!!info Information
This is mod is SERVER SIDE only, so you do not need it installed for your clients.
!!!

***

### Generating the Config File

Start your server with the mods installed, and a new file called `mmode.json` will be generated in your config folder.

You can now edit this file directly, or use the in game commands to configure the mod.

!!!danger Warning
When editing the config file directly, you need to use the `/maintenance reload` command to reload the config, so that changes can apply!
!!!
